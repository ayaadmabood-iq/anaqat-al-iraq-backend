# دستور المنصة — Platform Constitution

مأخوذ من IRPB الملف رقم 1 §8. يُذكر هنا للتشغيل والمرجعية داخل المستودع.

**المادة 1**: القرآن الكريم هو المرجعية العليا للمشروع.

**المادة 2**: منهج القراءة القصدية هو المنهج العلمي المعتمد.

**المادة 3**: المنصة مؤسسة مستقلة لا ترتبط بشركة تطوير أو مزود تقني بعينه.

**المادة 4**: جميع الأصول الرقمية والبيانات والأكواد وقواعد البيانات والدومين
والخوادم والنسخ الاحتياطية مملوكة للدكتور إياد محمد عبود أو للجهة القانونية التي
يحددها مستقبلاً.

**المادة 5**: أي تطوير جديد يجب أن يحافظ على قابلية التوسع والتوثيق وإمكانية
نقل النظام إلى فريق آخر دون قيود.

---

## قائمة التسليم النهائية (IRPB ملف 6 §9)

يجب أن يتسلم المالك:

- الكود الكامل (هذا المستودع).
- قاعدة البيانات (سكربتات البذر + بنية الجداول عبر TypeORM synchronize، ثم Migrations لاحقاً).
- وثائق API (README + دليل النقاط في `docs/OPERATIONS.md`).
- دليل النشر (`docs/DEPLOYMENT.md`).
- دليل النسخ الاحتياطي (`docs/BACKUP.md`).
- دليل الأدوار والصلاحيات (`docs/RBAC.md`).
- جميع كلمات المرور بعد تغييرها (تُسلَّم في مغلَّف مشفَّر).
- جميع مفاتيح API (SMTP، DNS، الاستضافة، Object Storage عند تفعيله).
- النسخ الاحتياطية الأخيرة.
- دليل الصيانة (يُضاف عند اعتماد Backup automation).
