# Storage layout — منصة القراءة القصدية

هذا المجلد يستضيف الملفات الثنائية للنظام. لا تُرفع محتوياته إلى Git.

```
storage/
├── books/           # النسخ الأصلية (Master PDF) لكل كتاب — يديرها المالك فقط
│   └── <slug>/master.pdf
├── generated/       # النسخ الشخصية المُنتَجة عند اعتماد الطلبات
│   └── <slug>/<orderNumber>-<uuid>.pdf
└── transfers/       # صور إشعارات الحوالات المصرفية التي يرفعها العملاء
```

- `books/` يجب أن يحتوي على ملف `master.pdf` واحد لكل كتاب. المسار النسبي
  يُخزَّن في العمود `books.master_pdf_path`.
- `generated/` تُكتَب فيه النسخ الشخصية تلقائياً بعد اعتماد الطلب من قِبل
  الإدارة. يُعاد توليدها من المعرفات إن حُذفت.
- `transfers/` تُخزَّن فيه صور إشعارات الحوالات — لا تُشارك مع العملاء وإنما
  تُستخدم في مراجعة الحوالات من لوحة الإدارة.
